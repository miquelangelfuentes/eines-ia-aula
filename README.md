# Eines IA per a l'aula
> **Xerrada-Taller per a docents (2 hores)**  
> **Servei Educatiu del Vallès Occidental II — Centre de Recursos Pedagògics (CRP)**

Web interactiva de suport per a la ponència i guia pràctica pas a pas per al professorat:
- Instal·lació i ús de **Google Antigravity**.
- Configuració de **GitHub** per primera vegada per a docents.
- Publicació de materials educatius amb **GitHub Pages** vs. **Google Sites**.
- Bones pràctiques: **Vibe Coding Responsable** per a la creació de recursos a l'aula.
