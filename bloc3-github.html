Configuració de GitHub per a docents

Com obrir el vostre espai al núvol, generar el vostre token d'accés personal i publicar el vostre primer recurs web sense pagar servidors.

GitHub explicat per a docents principiants

Com entendre el servei sense termes informàtics innecessaris

Penseu en GitHub com un gran magatzem públic de carpetes. Cada vegada que prepareu una activitat interactiva amb Google Antigravity, la guardeu en una carpeta de GitHub (anomenada repositori). A més de conservar totes les vostres versions de manera gratuïta, GitHub ofereix el servei GitHub Pages, que converteix automàticament aquesta carpeta en una pàgina web visible per a tothom.

El repositori (repo)

És la carpeta del vostre projecte. Per exemple: verbs-irregulars-angles. Perquè l'alumnat pugui accedir a la pàgina sense contrasenyes ni registres, el repositori ha de ser públic.

Commit i push

Fer un commit és desar una còpia de seguretat dels canvis amb una petita descripció (com ara "afegides 10 preguntes noves"). Fer un push consisteix a pujar aquesta còpia des del vostre ordinador cap al repositori de GitHub.

El token d'accés (PAT)

GitHub no permet utilitzar la contrasenya habitual per pujar fitxers des de programes externs. Es fa servir una credencial d'accés anomenada Personal Access Token que genereu una sola vegada i que actua com a permís segur.

Guia de credencials per a docents que entren per primer cop

Si mai no heu utilitzat GitHub, penseu en el Personal Access Token (PAT) com una credencial específica creada expressament perquè Google Antigravity o GitHub Desktop puguin desar feina al vostre compte sense conèixer la vostra contrasenya personal. Si algun dia canvieu d'ordinador o voleu retirar el permís, podeu revocar aquest token amb un sol clic sense canviar la contrasenya del vostre compte.

Drecera directa: podeu anar immediatament a la gestió de credencials a través d'aquest enllaç oficial: github.com/settings/personal-access-tokens.

Com generar el vostre token clàssic pas a pas:

1

Accediu directament a la configuració de tokens

Inicieu sessió a github.com i entreu directament a github.com/settings/personal-access-tokens (o feu clic a la vostra foto de perfil > Settings > Developer settings al final de la columna esquerra).

2

Trieu Tokens (classic)

Al menú lateral de tokens, feu clic a Tokens (classic). Premeu el desplegable Generate new token i seleccioneu Generate new token (classic).

3

Poseu-li nom i trieu la durada

A la casella Note escriviu un nom que identifiqui l'eina (per exemple, "Antigravity ordinador docent"). A Expiration trieu la durada que preferiu (per exemple, 90 dies o el curs escolar sencer).

4

Marqueu la casella repo i genereu el token

Marqueu la casella principal repo (això activa automàticament tots els permisos necessaris per crear i actualitzar repositoris educatius). Baixeu al final de la pàgina i feu clic al botó verd Generate token.

Important: copieu la cadena de caràcters que comença per ghp_... i deseu-la al vostre bloc de notes o gestor de contrasenyes. GitHub no la tornarà a mostrar mai més per motius de seguretat. Aquesta és la credencial que introduireu quan una eina externa us demani validar el vostre compte.

Com activar GitHub Pages en 3 clics:

1

Entreu a Settings del repositori

Obriu el repositori on heu desat la vostra activitat i feu clic a la pestanya Settings (la roda d'engranatge a la barra superior del repositori).

2

Feu clic a Pages

A la columna de l'esquerra, feu clic a la secció Pages.

3

Trieu la branca principal i premeu Save

A l'apartat Build and deployment > Branch, seleccioneu la branca main (o master) i la carpeta arrel / (root). Premeu Save.

Resultat: en un o dos minuts, GitHub us mostrarà l'adreça web pública del vostre recurs: https://el-vostre-usuari.github.io/nom-del-repositori/. Aquest enllaç és permanent, gratuït i segur (HTTPS).

Tres particularitats indispensables per no tenir errors:

1. El fitxer principal s'ha de dir `index.html`

Tots els servidors web necessiten saber quina és la pàgina inicial. Si l'arxiu es diu index.html (tot en minúscules), es carregarà de manera immediata en obrir l'adreça del repositori. Si l'anomeneu d'una altra manera (com inici.html o activitat.html), l'enllaç donarà un error 404 tret que l'alumnat n'escrigui el nom complet a la barra del navegador.

2. Les rutes han de ser relatives

Quan enllaceu imatges o fitxers desats a la vostra carpeta, no poseu una barra a l'inici. Feu servir rutes relatives com ara styles.css o imatges/mapa.png, en comptes de /styles.css. D'aquesta manera funcionarà correctament dins del subdomini de GitHub Pages.

3. El repositori ha de ser públic

Per activar GitHub Pages de manera gratuïta en comptes estàndard, el repositori ha d'estar configurat com a públic. Si per error el vau crear com a privat, el podeu canviar fàcilment a públic des de Settings > Danger Zone > Change repository visibility (veure videotutorial a YouTube ↗).

GitHub Desktop i portàtils docents del PEDC

Com gestionar els repositoris sense comandes de consola i consideracions sobre els equips escolars

Per als docents que s'inicien i prefereixen una aplicació gràfica d'escriptori, GitHub Desktop és una eina gratuïta molt recomanable. Permet afegir carpetes locals, veure els fitxers modificats i publicar canvis a GitHub Pages amb només prémer un botó.

Instal·lació en els portàtils del PEDC

Tant Google Antigravity com GitHub Desktop es poden instal·lar en el portàtil docent del Pla d'Educació Digital de Catalunya (PEDC) sense necessitat de privilegis d'administració, ja que tots dos s'executen i s'instal·len dins del directori de l'usuari local. Això no obstant, cal tenir present que algunes configuracions en certs dispositius poden ser més estrictes que d'altres depenent del perfil de polítiques del centre o de la configuració de xarxa.

Comparació entre GitHub i GitHub Desktop

Com que tenen noms semblants, és habitual que els docents es preguntin si són el mateix servei o quina eina cal emprar a cada moment. Aquesta taula en resumeix les diferències i funcions complementàries:

Aspecte GitHub (al núvol / web) GitHub Desktop (al vostre ordinador)
On s'executa Al navegador d'internet entrant a github.com. No requereix cap instal·lació. Com a aplicació local instal·lada al vostre disc dur (en Windows o macOS).
Instal·lació al PEDC Accés web immediat des de qualsevol dispositiu amb el vostre navegador habitual. Instal·lació local senzilla a la carpeta d'usuari sense necessitat de privilegis d'administració.
Funció principal Magatzem permanent al núvol, gestió d'usuaris i activació del servei d'allotjament GitHub Pages. Interfície visual còmoda per sincronitzar els fitxers de la vostra carpeta local amb el repositori al núvol.
Connexió a internet Requereix connexió constant a internet per visualitzar o modificar fitxers. Podeu consultar canvis i comprovar arxius sense connexió; només cal internet en prémer Push.
Comandes de terminal No calen per a la configuració bàsica de repositoris ni per activar Pages. Substitueix completament la consola de comandes per botons gràfics (Fetch, Commit, Push).
Com es complementen On configureu el vostre compte, creeu el repositori públic i activeu l'enllaç web que compartireu amb l'alumnat. On afegiu la carpeta del vostre recurs per pujar-hi els fitxers generats amb Antigravity en un sol clic.

Quan fer servir GitHub (web)?

  • Per crear el vostre compte docent i generar el repositori inicial.
  • Per entrar a Settings > Pages i obtenir l'adreça web pública del recurs.
  • Per generar i gestionar el vostre token d'accés personal (PAT).

Quan fer servir GitHub Desktop?

  • Per enllaçar la carpeta de treball local del vostre ordinador amb el repositori.
  • Per revisar quins fitxers ha creat o modificat Google Antigravity.
  • Per enviar les actualitzacions al núvol amb el botó Push origin en un segon.
