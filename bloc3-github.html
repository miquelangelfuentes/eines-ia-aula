Configuració de GitHub per a docents

Com obrir el teu espai al núvol, generar el teu token d'accés personal i publicar el teu primer recurs web sense pagar servidors.

GitHub explicat per a docents principiants

Com entendre el servei sense termes informàtics innecessaris

Pensa en GitHub com un gran magatzem públic de carpetes. Cada vegada que prepares una activitat interactiva amb Google Antigravity, la guardes en una carpeta de GitHub (anomenada repositori). A més de conservar totes les teves versions de manera gratuïta, GitHub ofereix el servei GitHub Pages, que converteix automàticament aquesta carpeta en una pàgina web visible per a tothom.

El repositori (repo)

És la carpeta del teu projecte. Per exemple: verbs-irregulars-angles. Perquè l'alumnat pugui accedir a la pàgina sense contrasenyes ni registres, el repositori ha de ser públic.

Commit i push

Fer un commit és desar una còpia de seguretat dels canvis amb una petita descripció (com ara "afegides 10 preguntes noves"). Fer un push consisteix a pujar aquesta còpia des del teu ordinador cap al repositori de GitHub.

El token d'accés (PAT)

GitHub no permet utilitzar la contrasenya habitual per pujar fitxers des de programes externs. Es fa servir una credencial d'accés anomenada Personal Access Token que generes una sola vegada i que actua com a permís segur.

Com generar el teu token d'accés (PAT) pas a pas:

1

Accedeix a la configuració del teu perfil

Inicia sessió a github.com, fes clic a la teva foto de perfil (a la cantonada superior dreta) i selecciona Settings.

2

Entra a Developer settings

A la columna de l'esquerra, baixa fins al final i fes clic a l'últim apartat: Developer settings.

3

Genera un token clàssic

Al menú lateral, fes clic a Personal access tokens i després a Tokens (classic). Prem el botó Generate new token i tria l'opció Generate new token (classic).

4

Marca el permís de repositoris i desa

Posa-li un nom descriptiu a la casella de nota (per exemple, "Antigravity docent") i marca la casella repo (això dóna accés per pujar i modificar els teus materials educatius).

Baixa al final de la pàgina i fes clic al botó verd Generate token.

Important: copia la cadena de caràcters que comença per ghp_... i guarda-la al teu gestor de notes o contrasenyes. GitHub no la tornarà a mostrar mai més. Aquest és el codi d'autenticació que faràs servir quan el programa et demani validar-te per primera vegada.

Com activar GitHub Pages en 3 clics:

1

Entra a Settings del repositori

Obre el repositori on has desat la teva activitat i fes clic a la pestanya Settings (la roda d'engranatge a la barra superior del repositori).

2

Fes clic a Pages

A la columna de l'esquerra, fes clic a la secció Pages.

3

Tria la branca principal i prem Save

A l'apartat Build and deployment > Branch, selecciona la branca main (o master) i la carpeta arrel / (root). Prem Save.

Resultat: en un o dos minuts, GitHub et mostrarà l'adreça web pública del teu recurs: https://el-teu-usuari.github.io/nom-del-repositori/. Aquest enllaç és permanent, gratuït i segur (HTTPS).

Dues particularitats indispensables per no tenir errors:

1. El fitxer principal s'ha de dir `index.html`

Tots els servidors web necessiten saber quina és la pàgina inicial. Si l'arxiu es diu index.html (tot en minúscules), es carregarà de manera immediata en obrir l'adreça del repositori. Si el nombres d'una altra manera (com inici.html o activitat.html), l'enllaç donarà un error 404 tret que l'alumne n'escrigui el nom complet a la barra del navegador.

2. Les rutes han de ser relatives

Quan enllacis imatges o fitxers desats a la teva carpeta, no posis una barra a l'inici. Fes servir rutes relatives com ara styles.css o imatges/mapa.png, en comptes de /styles.css. D'aquesta manera funcionarà correctament dins del subdomini de GitHub Pages.

GitHub Desktop i portàtils docents del PEDC

Com gestionar els repositoris sense comandes de consola i consideracions sobre els equips escolars

Per als docents que s'inicien i prefereixen una aplicació gràfica d'escriptori, GitHub Desktop és una eina gratuïta molt recomanable. Permet afegir carpetes locals, veure els fitxers modificats i publicar canvis a GitHub Pages amb només prémer un botó.

Instal·lació en els portàtils del PEDC

Tant Google Antigravity com GitHub Desktop es poden instal·lar en el portàtil docent del Pla d'Educació Digital de Catalunya (PEDC) sense necessitat de privilegis d'administració, ja que tots dos s'executen i s'instal·len dins del directori de l'usuari local. Això no obstant, cal tenir present que algunes configuracions en certs dispositius poden ser més estrictes que d'altres depenent del perfil de polítiques del centre o de la configuració de xarxa.

Comparació entre GitHub i GitHub Desktop

Com que tenen noms semblants, és habitual que els docents es preguntin si són el mateix servei o quina eina cal emprar a cada moment. Aquesta taula en resumeix les diferències i funcions complementàries:

Aspecte GitHub (al núvol / web) GitHub Desktop (al teu ordinador)
On s'executa Al navegador d'internet entrant a github.com. No requereix cap instal·lació. Com a aplicació local instal·lada al teu disc dur (en Windows o macOS).
Instal·lació al PEDC Accés web immediat des de qualsevol dispositiu amb el teu navegador habitual. Instal·lació local senzilla a la carpeta d'usuari sense necessitat de privilegis d'administració.
Funció principal Magatzem permanent al núvol, gestió d'usuaris i activació del servei d'allotjament GitHub Pages. Interfície visual còmoda per sincronitzar els fitxers de la teva carpeta local amb el repositori al núvol.
Connexió a internet Requereix connexió constant a internet per visualitzar o modificar fitxers. Pots consultar canvis i comprovar arxius sense connexió; només cal internet en prémer Push.
Comandes de terminal No calen per a la configuració bàsica de repositoris ni per activar Pages. Substitueix completament la consola de comandes per botons gràfics (Fetch, Commit, Push).
Com es complementen On configures el teu compte, crees el repositori públic i actives l'enllaç web que compartiràs amb l'alumnat. On afegeixes la carpeta del teu recurs per pujar-hi els fitxers generats amb Antigravity en un sol clic.

Quan fer servir GitHub (web)?

  • Per crear el teu compte docent i generar el repositori inicial.
  • Per entrar a Settings > Pages i obtenir l'adreça web pública del recurs.
  • Per generar i gestionar el teu token d'accés personal (PAT).

Quan fer servir GitHub Desktop?

  • Per enllaçar la carpeta de treball local del teu ordinador amb el repositori.
  • Per revisar quins fitxers ha creat o modificat Google Antigravity.
  • Per enviar les actualitzacions al núvol amb el botó Push origin en un segon.
