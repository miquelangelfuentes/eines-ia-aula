Marc Conceptual: De la IA que xateja a la IA que construeix

Superar la barrera tècnica per esdevenir creadors actius de materials d'aula

⏱️ 15 minuts (00:00 - 00:15)
💡 Idea força per projectar: Els xats d'IA ens donen respostes de text, però el Vibe Coding amb agents com Google Antigravity ens permet crear aplicacions web completes i interactives per als nostres alumnes en minuts.

💬 1. El límit dels xats convencionals

Generen textos, llistes o suggeriments, però després el docent ha de copiar, enganxar, maquetar o adaptar el format a mà. L'alumne continua rebent un document estàtic.

🪄 2. Què és el "Vibe Coding" educatiu?

És la metodologia de crear programari descrivint què vols aconseguir pedagògicament en llenguatge natural. L'agent d'IA s'encarrega del codi tècnic (HTML, CSS, JS).

🎯 3. L'objectiu d'aquesta sessió de 2h

Que cada docent assistent del Vallès Occidental II surti amb Google Antigravity configurat, entengui GitHub sense por i tingui la capacitat de publicar la seva primera pàgina interactiva gratuïta.

Notes del ponent per a la introducció:

  • Demanar quants docents a la sala han provat ChatGPT/Claude/Gemini per preparar classes (sovint el 90%).
  • Preguntar quants tenen una web pròpia interactiva amb simulacions o exercicis autocorrectius (sovint menys del 5%).
  • Subratllar que avui trenquem aquesta escletxa: no cal saber programar per tenir el teu propi entorn web d'aula.

L'Eina: Com instal·lar i configurar Google Antigravity

Passos d'instal·lació als dispositius docents i primer contacte amb l'entorn agentic

⏱️ 25 minuts (00:15 - 00:40)
🛠️ Idea força per projectar: Google Antigravity no és un xat web: és un entorn de desenvolupament assistit per agents que pot crear carpetes, escriure fitxers web complets i executar comprovacions directament al teu ordinador.

💻 1. Requisits i Descàrrega

Disponible per a Windows, macOS i Linux. Requereix connexió a Internet i un compte de Google/Google Workspace per accedir als models Gemini.

⚙️ 2. Estructura de treball (Workspaces)

Treballa sobre carpetes locals del teu ordinador (p. ex. Documents/Antigravity/el-meu-projecte). Tot el que crea l'agent es queda al teu disc dur abans de publicar-lo.

🗣️ 3. Com "parlar-li" a l'agent

No li demanis "fes-me un exercici". Dóna-li context pedagògic: curs, matèria, objectiu DUA, necessitat d'autocorrecció i format web autònom en un sol fitxer.

Guia d'instal·lació pas a pas per als docents:

Passos ràpids d'arrencada als dispositius 
1. Descarrega l'instal·lador oficial de Google Antigravity per al teu sistema operatiu (Windows .exe / macOS .dmg).
2. Obre l'aplicació i inicia sessió amb el teu compte educatiu o de Google.
3. Tria o crea una carpeta de treball: "C:\Docents\Materials-IA" o "~/Documents/Materials-IA".
4. Selecciona el model recomanat per a tasques complexes o ràpides (Gemini 2.5/3 Pro o Flash).
5. Ja pots escriure la teva primera instrucció en català!

El Hub Docent: GitHub per primera vegada

Perdre la por a Git: de la carpeta local al repositori públic gratuït

⏱️ 25 minuts (00:40 - 01:05)
🐙 Idea força per projectar: GitHub no és només per a enginyers de programari. Per a un docent, és l'armari definitiu de recursos: preserva el teu material, permet compartir-lo amb altres professors i et regala un servidor web d'alta velocitat per sempre.

🧑‍🏫 1. Registre i GitHub Education

Crear un compte a github.com. Consell docent: Si es valida el correu docent a GitHub Global Campus, s'obtenen eines educatives premium completament de franc.

🔑 2. Credencials fàcils (Tokens PAT)

GitHub ja no utilitza contrasenyes convencionals per pujar codi: es fa servir un Personal Access Token o bé l'autenticació que Google Antigravity i GitHub Desktop gestionen amb un sol clic.

🗂️ 3. El teu primer repositori

Crear un repositori anomenat les-meves-activitats. Marcar-lo com a Públic perquè els alumnes puguin visualitzar la pàgina sense requerir contrasenyes.

Desmitificant els termes de Git per a docents:

Terme informàtic Què és en realitat per a un docent? Exemple del dia a dia a l'institut
Repository (Repo) Una carpeta de projecte al núvol "La carpeta de la Unitat 1 de Ciències"
Commit Un punt de restauració / "Foto de seguretat" "Versió abans de canviar les preguntes del tema 2"
Push Pujar els canvis de l'ordinador a Internet Publicar les correccions perquè l'alumnat les vegi
Fork Fer una còpia pròpia d'un material d'un altre docent Agafar la web d'anglès d'un company i adaptar-la al teu grup
Comandes bàsiques (que l'agent d'Antigravity pot fer per tu) 
# 1. Iniciar el repositori
git init -b main

# 2. Afegir els fitxers creats
git add .
git commit -m "Primer recurs educatiu d'aula"

# 3. Connectar amb el repositori de GitHub i publicar
git remote add origin https://github.com/el-teu-usuari/el-teu-projecte.git
git push -u origin main

Publicació Web: Particularitats de GitHub Pages vs. Google Sites

Per què el pas de Google Sites a GitHub Pages obre un món infinit de possibilitats pedagògiques

⏱️ 25 minuts (01:05 - 01:30)
🌐 Idea força per projectar: Google Sites és com un tauler de suro on enganxem post-its i fitxers Drive. GitHub Pages és un autèntic laboratori web interactiu on la IA pot crear jocs, simuladors i eines que funcionen a qualsevol dispositiu.

Les 4 particularitats clau que tot docent ha de conèixer:

📄 1. El fitxer `index.html`

És la porta d'entrada obligatòria. Si el fitxer es diu index.html, en entrar a usuari.github.io/projecte es carregarà directament sense haver d'escriure la ruta sencera.

🔗 2. Rutes relatives (sense trencar res)

Enllaça imatges i fulls d'estil amb rutes com styles.css o imatges/foto.png (sense barra inicial /) perquè funcionin correctament dins del subdomini del repositori.

⚡ 3. Activació en 3 clics

Al teu repositori a GitHub: Settings ➔ Secció lateral Pages ➔ A Branch selecciona main ➔ Clic a Save. En 60 segons la teva web està al món!

🔒 4. Seguretat i zero cost

Inclou certificat HTTPS segur automàtic, càrrega instantània a través de servidors CDN globals, sense límit de visites de l'alumnat i sense anuncis ni tarifes.

Taula Comparativa a Fons: GitHub Pages vs. Google Sites

Criteri Pedagògic 🐙 GitHub Pages (amb IA / Vibe Coding) 📄 Google Sites (Edició manual clàssica)
Creació i actualització ⭐ Automatitzada
L'agent d'IA escriu i refà pàgines senceres, afegeix botons o crea exercicis en qüestió de segons a partir d'un prompt. 		⚠️ Manual i lenta
Has d'anar clicant blocs, arrossegant caixes de text, reajustant mides i enllaçant documents un per un.
Interactivitat i Recursos ⭐ Infinitament ric
Calculadores, canvas de dibuix, simuladors científics, exercicis amb cronòmetre, sintetitzadors d'àudio, jocs de lògica. 		⚠️ Molt limitat
Només textos, imatges, vídeos de YouTube i documents incrustats de Google Drive que s'obren en finestres incòmodes.
Control d'errors i Historial ⭐ Control de versions total
Cada canvi té una data i missatge. Si una modificació espatlla un exercici, es torna a la versió anterior amb un sol clic. 		⚠️ Risc de pèrdua
L'historial de Google Sites és confús; si sobreescrius o esborres seccions complexes, costa molt recuperar-les.
Sobirania i Portabilitat ⭐ Codi estàndard i lliure
HTML/CSS/JS funcionen a qualsevol ordinador, servidor o llapis de memòria USB, fins i tot sense connexió a Internet. 		⚠️ Jardí tancat (Vendor Lock-in)
Estàs atrapat a Google. No pots descarregar el codi font per portar-lo a una altra plataforma ni exportar-lo netament.
Col·laboració entre docents ⭐ Comunitat oberta (Fork)
Un company de seminari pot duplicar el teu repositori i adaptar-lo per al seu grup en 10 segons. 		⚠️ Rígid
Cal compartir permisos de correu, amb el perill que dos docents toquin la mateixa caixa i es trepitgin els canvis.

Bones Pràctiques: Vibe Coding Responsable a l'Aula

Deu recomanacions essencials per protegir l'alumnat, mantenir el rigor i compartir recursos

⏱️ 20 minuts (01:30 - 01:50)
🛡️ Idea força per projectar: Amb la IA anem molt ràpid creant coses maques, però la responsabilitat pedagògica i ètica és sempre del docent. La guia de referència de Juan José de Haro ens dóna el compàs.

Basat en la guia oficial de referència: vibe-coding-educativo.github.io/vibe-responsable/ca/guia.html. Aquests són els 4 eixos i 10 recomanacions aplicades directament a la nostra feina d'aula:

1

Revisar el contingut sense delegar-lo a la IA

La IA pot inventar fets o donar respostes falses per vàlides. Fes el recorregut del recurs complet com si fossis un alumne, també posant respostes errònies per comprovar la correcció.

📌 A l'aula: Mai posis un test generat sense haver comprovat que la solució és correcta.
2

No enviar dades personals de l'alumnat (RGPD)

Evita eines que demanin correus, noms o edats dels menors. La millor opció a GitHub Pages és treballar 100% en local al navegador (Client-Side), sense servidors externs que recullin dades.

📌 A l'aula: L'alumnat juga o fa activitats sense cap registre ni contrasenya.
3

Entendre què fa el material

No acceptis codi com una caixa negra. Demana a Google Antigravity: "Explica'm en llenguatge planer què fa aquest fitxer i com funciona per dins".

📌 A l'aula: Codi net i comentat per poder-lo corregir si alguna cosa falla el curs vinent.
4

No dependre de serveis efímers

Si una web carrega imatges d'enllaços externs desconeguts, l'endemà l'enllaç es trenca. Guarda imatges, icones SVG i estils dins del mateix repositori.

📌 A l'aula: El recurs ha de funcionar encara que la plataforma on el vas crear tanqui demà.
5

Fer-lo accessible a qualsevol persona (DUA)

L'efectisme visual de la IA sovint perjudica l'alumnat amb dificultats. Assegura bon contrast cromàtic, mida de lletra ajustable i que es pugui utilitzar només amb teclat.

📌 A l'aula: Disseny Universal per a l'Aprenentatge per atendre la diversitat del grup.
6

Citar l'autoria del que es pren d'altres persones

Textos, il·lustracions o codi de tercers tenen autoria. Afegeix una secció de crèdits al peu de pàgina amb l'origen de cada recurs.

📌 A l'aula: Donem exemple als alumnes sobre respecte a la propietat intel·lectual.
7

Guardar el rastre de com es va fer

Desa els prompts i la bitàcola de decisions en un document DECISIONS.md o al README.md del repositori. D'aquí a 6 mesos t'ajudarà a reprendre la feina.

📌 A l'aula: Facilita la continuïtat docent i la transferència entre departaments.
8

Declarar l'ús d'IA i el que s'ha comprovat

Sigues transparent: inclou un peu de pàgina que indiqui quina eina d'IA s'ha fet servir com a copilot i què ha validat el docent responsable.

📌 A l'aula: Cultura de transparència i ètica digital docent.
9

Publicar amb una llicència lliure a la vista

Els materials sense llicència generen inseguretat jurídica. Afegeix una llicència Creative Commons (CC BY-SA 4.0) per als continguts i MIT per al codi.

📌 A l'aula: Comparteix de debò perquè la xarxa docent creixi.
10

Oferir el codi perquè altres persones l'adaptin

No publiquis només el resultat final; comparteix l'enllaç al repositori de GitHub perquè un altre docent pugui fer un Fork i traduir-lo o personalitzar-lo.

📌 A l'aula: El repositori obert converteix el material en un recurs educatiu obert (REO).
