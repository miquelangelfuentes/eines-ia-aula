Eines d'intel·ligència artificial per a l'aula

Com passar de la idea docent a la publicació d'un recurs web interactiu fent servir Google Antigravity i GitHub Pages, amb criteris de Vibe coding responsable.

Aquesta guia està organitzada en pàgines independents per seguir la ponència pas a pas o consultar cada apartat de manera autònoma. Pots navegar fent clic a les targetes, amb els botons inferiors o utilitzant les tecles de fletxa del teclat (◀ / ▶).
