Llicències: Creative Commons i llicències de codi obert

Com indicar què poden reutilitzar altres persones i quines condicions han de mantenir.

Per què cal distingir entre contingut i codi?

Una web educativa pot funcionar alhora com a material didàctic i com a programa. Per això convé separar què esteu llicenciant abans d'escollir la llicència.

La pregunta inicial no és quina llicència voleu, sinó quina part del projecte és vostra i voleu compartir. El contingut pedagògic i el codi tenen necessitats diferents. Els recursos de tercers conserven les seves condicions originals.

Contingut pedagògic

El material que una persona llegeix, consulta o utilitza per aprendre.

Hi pot entrar el text explicatiu i les activitats pròpies. També hi poden entrar altres materials originals que hàgiu creat.

La llicència decideix si altres persones poden copiar el material o adaptar-lo i què han de mantenir quan el tornen a compartir.

En aquest projecte el contingut pedagògic propi es publica sota CC BY-SA 4.0.

Codi font

El programari que construeix el recurs o en controla el comportament.

Hi pot entrar el codi que estructura la pàgina i els scripts que fan possible la interacció.

La llicència decideix com es pot reutilitzar aquest programa i quines obligacions apareixen quan se'n comparteixen versions modificades.

En aquest projecte el codi propi es publica sota GNU GPL v3.

Per què no una sola llicència?

Creative Commons recomana no aplicar les seves llicències al programari. Les llicències de codi estan pensades específicament per regular la reutilització del programari.

Recomanació de Creative Commons

I el que no heu creat vosaltres?

Una biblioteca de codi o una fotografia no canvien de llicència pel fet d'incorporar-les al projecte. Cal conservar-ne la llicència original i els avisos exigits.

Com queda en aquest projecte?

La separació queda documentada al repositori perquè una persona que reutilitzi el projecte pugui identificar què pot fer amb cada part.

Model de declaració per a un recurs web

La declaració pot aparèixer al README.md i a la pàgina de crèdits. Els recursos de tercers queden fora d'aquesta declaració general.

Model de declaració
Aquest recurs educatiu obert es distribueix amb llicències diferenciades:
- El contingut pedagògic propi es publica sota Creative Commons Reconeixement-CompartirIgual 4.0 Internacional (CC BY-SA 4.0).
- El codi font propi es publica sota GNU General Public License v3.0 (GPL-3.0-only).
Els recursos de tercers mantenen les seves llicències i condicions pròpies.

Quina llicència de codi encaixa amb el vostre projecte?

No cal conèixer les llicències abans de començar. L'orientador us preguntarà què voleu permetre i només us mostrarà les preguntes que afecten la vostra decisió.

El qüestionari se centra en llicències de programari. Els noms tècnics apareixen al resultat, després d'haver pres les decisions amb exemples comprensibles.

Llicències recomanades per a docents

Primer identifiqueu si esteu compartint contingut educatiu o codi. A partir d'aquí, compareu només llicències pensades per al mateix tipus d'obra.

Per a continguts

Creative Commons ofereix llicències pensades per a textos, activitats i altres materials educatius. La diferència principal és què voleu permetre quan altres persones reutilitzen el material.

LlicènciaQuè permetQuan pot encaixar
CC BY 4.0 Permet compartir i adaptar el material, també per a usos comercials, amb atribució. Quan voleu facilitar una reutilització molt àmplia i l'atribució és la condició principal.
Opció del projecte
CC BY-SA 4.0		 Permet compartir i adaptar el material amb atribució. Les adaptacions compartides han d'utilitzar la mateixa llicència o una de compatible. Quan voleu que les adaptacions continuïn obertes sota una condició de CompartirIgual.
CC BY-NC 4.0 Permet compartir i adaptar el material amb atribució, però no per a usos comercials. Quan la restricció d'ús comercial respon a una decisió deliberada del projecte.
CC BY-NC-SA 4.0 Afegeix la restricció NoComercial i exigeix CompartirIgual en les adaptacions que es publiquin. Quan voleu limitar l'ús comercial i mantenir la reciprocitat en les adaptacions.
Compte amb ND. Les llicències amb SenseObraDerivada no permeten compartir versions adaptades. Això pot limitar usos educatius habituals com traduir un material o transformar-lo per adaptar-lo a un altre context.

Per al codi

Aquí convé comparar models que prenen decisions diferents sobre les versions modificades, l'ús en xarxa o les patents. No cal tractar com a opcions principals totes les llicències permissives que existeixen.

LlicènciaModelQuan aporta un contrast útil
Opció del projecte

Cas específic - GNU LGPL v3

Pot tenir sentit si publiqueu una biblioteca de programari que voleu mantenir oberta però que també ha de poder ser utilitzada des d'altres programes. Per a una web educativa habitual no acostuma a ser la primera opció que cal comparar.

GNU LGPL v3

ISC com a llicència de tercers

Lucide utilitza la llicència ISC. En aquest taller no cal presentar-la com una alternativa principal a MIT, perquè totes dues són permissives i s'encavalquen molt per a projectes senzills. El que sí cal és respectar l'ISC quan incorporem Lucide i conservar els avisos corresponents.

ISC License
Per a aquest projecte, GNU GPL v3 continua sent una opció coherent. És una web estàtica publicada amb GitHub Pages, de manera que la protecció específica d'AGPL v3 per a programari modificat que funciona només al servidor aporta poc valor addicional en aquest cas.
