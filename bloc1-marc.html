Bloc 1

De consultar un xat a crear les nostres eines

Què canvia quan la intel·ligència artificial deixa de ser només un espai de consulta i passa a intervenir en un projecte web que queda sota control docent.

Creeu recursos web amb l'assistència de la IA

Un xat us pot ajudar a redactar una activitat. Quan la IA treballa sobre un projecte que existeix fora de la conversa, podeu convertir una idea docent en un recurs interactiu que continua evolucionant amb les vostres decisions.

Per exemple, podeu crear una activitat interactiva de vocabulari per al vostre alumnat en què cada resposta generi retroacció immediata. A partir d’aquí, podeu ajustar el contingut a les necessitats del vostre grup i preparar el recurs perquè l’alumnat hi pugui accedir com una pàgina web.

Aquest enfocament amplia les possibilitats de la IA per crear materials docents que podeu continuar desenvolupant i reutilitzar.

D'una resposta a un projecte

Una resposta generada dins d'un xat depèn de la conversa. Un projecte web, en canvi, queda desat en una carpeta amb un fitxer principal i els recursos que necessita. Això permet continuar-hi treballant sense haver de tornar a començar cada vegada que canvieu d'eina o de sessió.

Entendre el recurs sense escriure'l tot a mà

No cal saber programar des de zero per crear amb assistència d'IA, però sí reconèixer com s'organitza una web. Saber on és index.html, com s'enllacen els fitxers i què depèn d'un servei extern permet revisar millor el que genera l'agent i detectar problemes abans de publicar.

Aquest procés s'emmarca en el que el TERMCAT denomina programació per intenció o codificació per intenció. La persona defineix què necessita i revisa el resultat, mentre que l'assistent genera o modifica el codi necessari per materialitzar aquella intenció.

Per què s'ha triat Google Antigravity i GitHub?

Dues eines amb funcions diferents dins del mateix recorregut de treball

No són les úniques eines possibles ni cal utilitzar sempre aquesta combinació. En aquest taller les fem servir perquè cobreixen moments diferents del procés. Antigravity treballa sobre el projecte al dispositiu. GitHub conserva els fitxers i permet publicar-los. Així es pot veure com una indicació acaba convertida en un recurs web que continua existint fora de l'assistent d'IA.

Crear i revisar

Google Antigravity

S'ha triat perquè l'agent pot treballar directament sobre la carpeta del projecte, modificar-ne els fitxers i comprovar el resultat al navegador. La pràctica se centra així en les decisions docents sense haver de traslladar manualment el codi des d'un xat.

En aquest taller el projecte queda a la carpeta de Documents i continua sent accessible fora de l'assistent. El podeu obrir i revisar encara que després treballeu amb una altra eina d'IA.

Conservar i publicar

GitHub

S'ha triat perquè els mateixos fitxers es poden desar en un repositori amb historial de versions i publicar amb GitHub Pages sense convertir-los a un format propietari. L'alumnat accedeix al resultat amb un enllaç i no necessita un compte de GitHub.

En aquest taller continuem amb la mateixa carpeta creada a Antigravity. Als equips PEDC, la primera pujada es pot fer amb un token fine-grained temporal i restringit al repositori de la pràctica, sense fer dependre la sessió d'una instal·lació local de Git.

Control de versions
Què vol dir GitHub?
Git és un sistema de control de versions que registra els canvis d'un projecte al llarg del temps i permet recuperar versions anteriors. Hub vol dir centre o punt de trobada. El nom GitHub fa referència, per tant, a un espai on allotjar i compartir repositoris Git. Més informació sobre Git a la Viquipèdia.
La combinació és intencionada. Antigravity actua sobre els fitxers locals i GitHub els conserva fora de l'assistent. Quan el repositori es publica amb GitHub Pages, el mateix projecte es converteix en el lloc web que obre l'alumnat.
